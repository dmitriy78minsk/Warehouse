# Warehouse
Тестовое задание

1. Запускаем скрипты из каталога SQL для создания каркаса БД
2. В Win32\Debug\ заполяенм файл config.ini
3. Компилируем и запускаем проект

Схема таблиц и связи лежат в файле schema.png

Интерфейс

Верхняя панель
  - Кнопки создания справочников
  - кнопки добавления товара и списания товара по FIFO

Списание товара вручную повешено на контекстное меню в grid
